# TPS Notebook Navigator 9.0.0

This major release displays stored metadata and removes retired collection machinery. Minimum Obsidian: 1.11.0.

## Changes

- Removed GCM's generated-property overlay from icon/color display, sorting, grouping and invalidation. Existing
  frontmatter and explicit Navigator appearance settings remain. Generated-only presentation no longer appears.
- Deleted the unmounted inline Types adapter/store, three task-list call sites, task hydration cache, batching code and
  exclusive Markdown-body index. The active File Types API is separate and remains read-only. These dead modules already
  had zero production owners; their deletion is a structural reduction, not evidence of faster active navigation.
- Removed obsolete task transport contracts while preserving shared property-definition, native-record inspection and
  explicit property-edit adapters.
- No note, setting or IndexedDB migration. Normal metadata updates, nested property groups, file navigation, explicit
  rename and provider-owned rows remain.

Runtime source: 11 additions, 3,013 deletions, net -3,002. Generated-overlay preparation/subscription/cache ownership is
removed. The deleted inline store contributes zero active timers/listeners before and after because it had no production
imports. No replacement scheduler, cache, watcher or repair system is added.

## Validation

Final version 9.0.0: 3,397 tests passed in 288 files. Retired feature tests were removed with their implementation;
retirement coverage asserts the modules/resolvers are absent. One hundred file-catalog passes preserve note/Base buckets
with zero raw/cached/binary body reads or writer entries. Existing stored appearance, property grouping, native-record,
creation/rename and lifecycle suites pass.

Lint: zero errors, 26 existing warnings. TPS namespace check passed. Final separate TypeScript/production build deployed
only to Obsidian Plugin Test Vault. The 9.0.0 manifest reloaded; public types.whenReady() returned ready with all eight
file categories. Native UI retained Navigator's folder/list panes and the active Navigation 20 note with its original
body and property controls. No real settings or outbound automation were enabled.

Integrated foreground measurements (five per group): warm reload before median/worst 6066.2/7142.1 ms, cleaned
6084.7/7143.5 ms, TPS disabled 6360.5/6755.1 ms; long tasks 14/15/10. Navigation before 897.2/1134.5 ms, cleaned
838.9/892.9 ms, disabled 427.3/529 ms. The median no-regression threshold passed; remaining enabled/disabled navigation
gap is disclosed. Sequential combined-plugin measurements are not Navigator-specific attribution or production
cold-start evidence. Removing the final unmounted modules produced a byte-identical bundle; the versioned manifest is
separate. Physical iPhone acceptance remains unverified.

## Rollout and rollback

Tested in the test vault and ready for the user's BRAT pull. Production was not installed or reloaded. GCM's
corresponding cleanup removes the old projection/inline collection APIs; this Navigator no longer calls them.
Downgrading may restore generated presentation when an older GCM provides it. Existing notes/state are never restored or
overwritten as part of rollback. Upstream Notebook Navigator remains independently installed and untouched; namespace
and license notices are preserved.
