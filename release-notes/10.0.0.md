# TPS Notebook Navigator 10.0.0 — Remove retired inline-row preferences

Five inactive preferences are removed from types, defaults, normalization and saved payloads:
`tpsResourceCreationTarget`, `tpsResourceCreationSpecificFile`, `tpsGcmTaskRowsEnabled`,
`tpsGcmTaskRowsIncludeCompleted` and `tpsGcmTaskRowsPerNote`. Their obsolete validator, type and row-limit constants are
removed. Whole-file navigation, File types, ordinary note task-progress counts, property discovery/value renaming and
supported calendar templates remain unchanged.

The existing settings controller omits these values during load and normal saves without adding a startup write. The
one-way upstream importer still rejects the retired TPS-only keys. Current profile/sync choices, icon metadata, user
configuration, unknown extension state and historical migration markers remain. The existing native settings
destinations, default route, disclosures, mobile layout and upstream identities are unchanged; no new UI or settings
state is introduced.

## Compatibility and migration

This is a major release because legacy persisted settings are removed from the supported configuration contract. Minimum
Obsidian remains **1.11.0**. Existing functioning settings, commands and workflows retain their owners. Retired keys are
omitted by existing settings-save paths; no new startup save, note rewrite, watcher, poller, repair loop or cleanup
service is introduced. Credentials, execution state and migration markers remain protected.
